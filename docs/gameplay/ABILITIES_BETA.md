# Poderes do Beta

O jogador escolhe **2 poderes ativos entre 4 disponíveis** antes da run.

## Predação
Status: conceito aprovado / valores OPEN.

Direção:
- habilidade ligada ao vampirismo;
- pode interagir com Sangue, sustain ou execução.

## Familiar Sombrio
Status: conceito aprovado / implementação OPEN.

Direção:
- manifestação/familiar sobrenatural;
- pode interagir com Almas;
- Baskerville é referência canônica relevante para desenvolvimento futuro.

## Marca Carmesim
Status: conceito aprovado / implementação OPEN.

Direção:
- marcar alvo;
- pode criar sinergia com Casull, execução ou dano subsequente.

## Maré de Sangue
Status: conceito aprovado / implementação OPEN.

Direção:
- poder de área;
- leitura visual baseada em sangue/sombra;
- custo e comportamento finais OPEN.

## Regra do Beta
Implementar primeiro apenas um poder funcional para validar arquitetura.
Depois expandir para os quatro.
