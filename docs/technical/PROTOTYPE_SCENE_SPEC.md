# Prototype Arena 01

## Objetivo
Ser a cena mínima para testar o jogo.

## Conteúdo
- piso plano;
- limites simples;
- player placeholder/Alucard;
- 3 a 5 DummyEnemies;
- câmera elevada;
- HUD provisório;
- botões touch provisórios.

## Deve permitir
- movimentação;
- auto-target;
- mira manual;
- tiro;
- weapon swap;
- dash;
- um poder;
- dano;
- morte do inimigo;
- reset rápido.

## Não deve conter
- arte final;
- iluminação cinematográfica;
- cenário complexo;
- loot final;
- narrativa;
- menus completos.
